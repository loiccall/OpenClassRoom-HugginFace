## version API Hugging Face
Ce projet utilise l'API d'inférence Hugging Face (huggingface_api_cloth_seg.ipynb), qui nécessite un token personnel et un paiement.

1. Clonez ce dépôt.
2. Créez un compte sur https://huggingface.co si vous n'en avez pas déjà un.
3. Générez un token d'accès sur https://huggingface.co/settings/tokens (droits "Read" suffisent).
4. Copiez le fichier `.env.example` en `.env` :
5. Ouvrez `.env` et remplacez la valeur par votre propre token : HF_TOKEN=hf_votre_token_ici
6. telecharger les donnees photos exemple : https://s3.eu-west-1.amazonaws.com/course.oc-static.com/projects/2053_AI+Engineer/top_influenceurs_2024-20250314T143221Z-001+(1).zip
